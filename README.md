# github-stacks-demo

A tiny project used to demonstrate **GitHub Stacks** (native stacked pull requests) to the team.

The code here is deliberately trivial. The point of the repo is the _workflow_: how a
change that naturally splits into dependent layers is built, reviewed, and — the part
that actually hurts today — **rebased** when `main` moves or a lower layer changes.
